# MH Sports Massage website

Open `index.html` in a browser or use VS Code Live Server.

## Media
The actual MH logo is in `assets/logo.JPG`. The hero and treatment cards now use a mix of the original photos and the three newly supplied WhatsApp photos. Browser-friendly copies are named treatment-hero.jpg, treatment-back.jpg and treatment-shoulder.jpg; the originals are included. The supplied MOV was converted to `assets/treatment-video.mp4` with a video poster. The video appears in the **See the Treatment** section with playback controls.

## TOTS-OS booking
All Book buttons use `config.js` and `script.js`. Booking remains in pending mode until a real TOTS-OS booking URL or supported embed is configured. No Setmore booking is used.

## Before launch
Confirm service names, packages, opening hours, qualifications, privacy policy, and rights/consent to publish identifiable client images and video. Never collect health consultation information using an unsecured static form.
